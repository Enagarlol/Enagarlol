## 👋 Sobre mí

Soy **Ingeniero en Software** de Tapachula, Chiapas, con **4 años de experiencia trabajando 100 % remoto**. Construyo software de punta a punta: del modelo de datos y la API a la interfaz que usa la gente.

- 🏢 He desarrollado puntos de venta, plataformas para el sector asegurador y APIs para gestión académica.
- 🖥️ Hoy trabajo sobre todo con **C# / .NET**, **WinUI 3**, **ASP.NET** y **SQL Server**.
- 🤖 Uso la **IA como parte de mi flujo de trabajo** (Claude, Codex, ChatGPT) y la integro en productos como chatbots y automatizaciones.
- 🌎 Abierto a posiciones remotas como **Full Stack** o **Backend .NET**, y a proyectos freelance.
